# Bàn giao cho Claude Code

1. Giải nén thư mục `vung-xanh/`.
2. Mở terminal trong thư mục đó và chạy `claude` (hoặc mở thư mục trong Claude Code desktop / VS Code).
3. Claude Code tự đọc `CLAUDE.md`. Câu lệnh gợi ý đầu tiên:
   - "Đọc CLAUDE.md và docs/level_design.md, đề xuất stack (Phaser 3 hoặc Godot 4) rồi dựng khung dự án màn 1."
   - "Dùng prototype/build_hub.html làm điểm xuất phát, tách JS ra module, thêm lưới va chạm cho màn 1."
4. Nên đưa thư mục lên một repo Git để lưu lịch sử thay đổi.
